# Функциональное описание системы заявок в поддержку

## Цель

Создать простой интерфейс, через который пользователь сможет отправить обращение в службу поддержки, а администратор — просмотреть отправленные обращения и указать результат их обработки.

## Роли пользователей

### Пользователь

Пользователь может:

- открыть главный экран системы;
- заполнить заголовок обращения;
- описать проблему в тексте обращения;
- отправить заявку.

### Администратор

Администратор может:

- перейти в административную панель;
- просмотреть все отправленные заявки;
- отклонить заявку;
- отметить заявку как решенную.

## Требования к главному экрану

Главный экран должен содержать заголовок **«Система заявок в поддержку»** и форму отправки заявки.

Форма должна включать:

- обязательный инпут **«Заголовок обращения»**;
- обязательный инпут или текстовую область **«Текст обращения»**;
- кнопку **«Отправить заявку»**.

В левом нижнем углу главного экрана должна находиться небольшая кнопка **«Админ панель»**. Нажатие на кнопку открывает административную панель.

## Требования к заявке

Заявка создается после успешной отправки формы и содержит заголовок, текст и статус. Начальный статус каждой новой заявки — **«Новая заявка»**.

## Требования к административной панели

Все отправленные заявки должны отображаться в виде карточек. В каждой карточке необходимо показать заголовок и текст обращения.

Слева у карточки должна располагаться вертикальная полоска, цвет которой соответствует текущему статусу заявки. В нижней части карточки должны находиться две кнопки:

- красная **«Отклонить»** — устанавливает статус **«Отклоненная заявка»**;
- зеленая **«Решить»** — устанавливает статус **«Решенная заявка»**.

После изменения статуса цвет полоски карточки должен обновиться.

## Справочник статусов

| Статус | Цвет индикатора |
| --- | --- |
| Новая заявка | Желтый |
| Отклоненная заявка | Красный |
| Решенная заявка | Зеленый |

## Ограничения текущего этапа

На текущем этапе требуется подготовить только текстовое описание в Markdown-файлах. Верстка формы, административной панели, база данных и API пока не реализуются.
