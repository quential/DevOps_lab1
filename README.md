# Система заявок в поддержку

## Назначение


Система предназначена для отправки пользователями обращений в службу поддержки и их обработки администратором. Пользователь создает заявку через форму, а администратор просматривает все отправленные заявки и меняет статус заявок.


## Главный экран

На главном экране должны отображаться:

- заголовок **«Система заявок в поддержку»**;
- форма отправки обращения;
- небольшая кнопка **«Админ панель»** в левом нижнем углу экрана.

### Форма отправки обращения

Форма содержит следующие элементы:

1. Поле **«Заголовок обращения»** — краткое описание проблемы.
2. Поле **«Текст обращения»** — подробное описание проблемы или вопроса.
3. Кнопка **«Отправить заявку»**.

Оба поля обязательны для заполнения. После нажатия кнопки «Отправить заявку» создается новая заявка со статусом **«Новая»**.

## Заявка

Каждая заявка должна содержать:

- заголовок обращения;
- текст обращения;
- текущий статус.

Новая заявка сразу после создания получает статус **«Новая заявка»**. В дальнейшем администратор может изменить статус на «Отклоненная заявка» или «Решенная заявка».

## Административная панель

Переход в административную панель выполняется по кнопке **«Админ панель»** на главном экране.

В административной панели отображаются все отправленные заявки в виде отдельных карточек.

### Карточка заявки

Карточка заявки должна включать:

- цветную полоску слева, обозначающую текущий статус;
- заголовок обращения;
- текст обращения;
- две кнопки управления в нижней части карточки:
    - красную кнопку **«Отклонить»**;
    - зеленую кнопку **«Решить»**.

После нажатия кнопки управления статус заявки меняется, а цвет левой полоски обновляется.

## Статусы заявок

| Статус | Цвет | Значение |
| --- | --- | --- |
| Новая заявка | Желтый | Обращение создано и еще не обработано администратором. |
| Отклоненная заявка | Красный | Обращение отклонено и не будет принято в работу. |
| Решенная заявка | Зеленый | По обращению принято решение или проблема устранена. |

Цветной индикатор должен быть заметен на каждой карточке и соответствовать ее текущему статусу.

## Основные сценарии

### Создание заявки

1. Пользователь открывает главный экран.
2. Заполняет заголовок и текст обращения.
3. Нажимает **«Отправить заявку»**.
4. Система создает заявку со статусом **«Новая заявка»**.

### Отклонение заявки

1. Администратор открывает административную панель.
2. Находит нужную карточку.
3. Нажимает красную кнопку **«Отклонить»**.
4. Заявка получает статус **«Отклоненная заявка»**, а левая полоска становится красной.

### Решение заявки

1. Администратор открывает административную панель.
2. Находит нужную карточку.
3. Нажимает зеленую кнопку **«Решить»**.
4. Заявка получает статус **«Решенная заявка»**, а левая полоска становится зеленой.

## Критерии готовности описанного функционала

- На главном экране отображается заголовок **«Система заявок в поддержку»**.
- В форме есть поля заголовка и текста обращения.
- В форме есть кнопка **«Отправить заявку»**.
- Кнопка **«Админ панель»** расположена в левом нижнем углу.
- В административной панели заявки отображаются карточками.
- У каждой карточки есть цветная полоска статуса.
- В карточке есть кнопки **«Отклонить»** и **«Решить»**.
- Для новой заявки используется желтый цвет, для отклоненной — красный, для решенной — зеленый.
